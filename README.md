# Lucky Digital Portfolio

A static website (HTML, CSS, JavaScript). No build step, no dependencies.

Files: `index.html`, `style.css`, `script.js`, `favicon.svg`, `README.md`

## Preview
Open `index.html` in any browser.

## Deploy
1. Upload all files to the root of a GitHub repository.
2. Go to vercel.com, sign in with GitHub, tap **Add New > Project**, pick the repository, then **Deploy**. No settings need changing.
   (GitHub Pages also works: Settings > Pages > Deploy from branch `main`, folder `/root`.)

## Edit
- Contact details: search for `2348031350375` and `Bringenrabo@gmail.com` in `index.html` and `script.js`.
- Prices and text: edit `index.html`.
- Colours: edit the variables at the top of `style.css`.

The inquiry form does not send email or store data. It opens WhatsApp with the message ready to send.

## Admin (Supabase)
See `SETUP.md` and `supabase.sql`. Fill in `config.js`, then open `/admin.html`.
